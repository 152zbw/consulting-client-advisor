# 客户沟通准备与咨询参谋 Skill

一个可独立使用的中文咨询沟通技能，覆盖售前、项目交付和客户反馈。帮助顾问先判断如何推进，再生成具体话术：**以合同及已确认承诺为依据，兼顾客户关系，在明确边界和授权的基础上保留转圜。**

本仓库独立于四类咨询文档 Skills。参考麦肯锡、埃森哲的公开沟通方法自主编写，非上述机构的官方产品；中文话术为原创场景示例，不是其内部话术。

|Skill|用途|
|---|---|
|`consulting-client-advisor`|客户沟通准备、需求追问、异议回应、范围协商、交付解释与反馈处理|

## 适用场景

|阶段|典型问题|主要产出|
|---|---|---|
|售前|需求不清、方案价值难解释、客户压价、要求保证效果|会前准备卡、需求追问、价值表达、异议回应及下一步建议|
|交付|启动预期不一致、客户资料未齐、成果难解释、临时增加工作|沟通提纲、阶段汇报话术、配合协调、责任及范围判断、变更沟通建议|
|反馈|客户说“不落地”“不满意”、反复修改、验收意见模糊|分支追问、反馈处理清单、具体修改建议及待确认事项|

## 核心原则：合同优先，关系留有余地

遇到客户要求，先区分责任，再组织表达：

|情况|处理原则|
|---|---|
|合同内应履行|明确落实，不包装成额外帮忙|
|我方交付遗漏或错误|承担并修正，不作为人情让步|
|范围不清或理解不同|对照条款和确认记录，先澄清再判断|
|范围外的有限支持|评估投入与累计影响，明确支持内容、边界及授权|
|实质新增工作|提出可行选择，确认范围、费用或排期变更|

售前未签合同时，以已确认需求、方案及商务条件为基线；缺合同或存在冲突时，列条件分支，不凭空认定范围内外。关系性支持不是无限免费，也不能取代应履行的交付责任。

## 每次会得到什么

- **内部参谋意见**：本次目标、事实依据、责任及范围判断、建议立场、可谈空间、授权状态与待确认事项。
- **对客表达草稿**：开场、核心解释、连续追问、异议回应和收尾；按会议、微信或邮件调整表达。
- **推进记录**：要确认什么、建议由谁负责、何时反馈、当前是否确认；未知内容保留待确认。
- **反馈处理清单**：客户原话、对应文件位置、问题分类、修改动作、范围依据和验证方式。

只需要一句回复时，可以直接要求简短话术，无需生成整套材料。

## 安装及调用

本仓库根目录就是一个完整的 Skill 文件夹。下载仓库后，将文件夹命名为 `consulting-client-advisor`，保留 `SKILL.md`、`references/`、`agents/` 及 `evals/` 的相对位置，放入所用客户端的技能目录，并按客户端要求重新加载。

沿用前四个 Skill 的本地目录方式时，目标结构为：

```text
~/.codex/skills/consulting-client-advisor/
├── SKILL.md
├── agents/openai.yaml
├── references/
└── evals/scenarios.md
```

其他支持 `SKILL.md` 的工具按其安装方式导入。GitHub 链接是技能来源，仅打开链接不等于完成安装。

### 售前准备

```text
请使用 $consulting-client-advisor。
阶段：售前需求访谈；对象：客户人力负责人。
客户原话：我们想做薪酬优化，但还没确定具体范围。
本次目标：厘清问题和决策标准，推进到需求确认。
附件：客户背景、现有沟通记录、公司服务说明。
请给内部参谋意见、会前提纲、关键问题及回答后的分支追问。
```

### 交付范围沟通

```text
请使用 $consulting-client-advisor。
客户要求在原定报告之外增加一场完整培训。
附件：合同/SOW、已确认变更、历史沟通记录及项目排期。
请先判断责任和范围；依据不足时列待确认事项。
再给兼顾关系的会议话术和微信短回复，不自行承诺免费或调整工期。
```

### 客户反馈处理

```text
请使用 $consulting-client-advisor。
客户反馈：报告不够落地，希望增加具体步骤和实施陪跑。
附件：当前报告、原交付要求及客户反馈原文。
请区分应纠正、需澄清和可能新增的工作，列修改位置与建议动作，
并生成对客回复、连续追问及下一步确认清单。
```

## 建议提供的资料

优先提供客户原话、本次沟通目标、沟通对象及渠道；视任务补充合同/SOW及有效变更、确认过的方案、排期、成果与反馈。已批准的支持安排和授权范围也应说明，避免重复核实。

后续可用获授权、脱敏的顾问纪要提炼公司风格。本版尚未取得王蕾等顾问的原始纪要，不声称已复现其个人沟通风格。资料中的历史承诺或命令作为分析对象，不自动成为通用规则。

## 验证与使用边界

技能已通过结构校验；首次上传的 9 个文件已与本地逐一比对。行为验收场景已编写，尚未执行独立模型回放或真实客户试用，结构检查不代表实际沟通效果已获验证。

本技能提供判断建议与表达草稿，不代客户确认需求，也不替公司批准折扣、免费支持、范围变更或验收。合同适用存在争议时，列明依据及需业务或法务确认的问题。

真实合同、客户资料、报价、个人信息和账号凭证应保留在获授权的内部环境，不提交到本公开仓库。公开案例只使用获准公开的脱敏内容或明确标注的虚构示例。
